重複判定アーカイバ

重複のないファイル集合を作る先。.akasyx/archive.db がここに置かれます。

重複しなかったものだけが保存用フォルダへ移動されます（重複はここに残ります）。

保存先

作成日の年月フォルダ（YYYY-MM/）の下に、投入元フォルダ名と投入元の階層をそのまま再現します。 ファイルが直接入るフォルダが上限件数に達すると 001/, 002/, … の枝に入ります。

オプション

保存フォルダの実体と DB を突き合わせます。ファイルは一切動きません。

処置予定フラグ（disposition=quarantine）を立てる種別

add で投入元に据え置いた重複を、2点検証のうえで削除（または退避）します。

保存フォルダの状態と実行履歴を表示します。DB も実体も変更しません。

詳細設定（既定のままで構いません）

保存フォルダの外・ローカルディスクに置きます。保存フォルダはこの DB の中で ID 管理され、複数登録できます。
